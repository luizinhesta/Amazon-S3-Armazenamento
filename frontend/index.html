📚 Classes de Armazenamento S3

S3 Standard

Acesso frequente com baixa latência. Ideal para documentos ativos que são acessados regularmente. Sem tempo mínimo de armazenamento.

Acesso frequente

S3 Intelligent-Tiering

Move objetos automaticamente entre níveis de acesso conforme o padrão de uso. Taxa de monitoramento por objeto. Ideal para padrões de acesso imprevisíveis.

Otimização automática

Glacier Flexible Retrieval

Arquivamento com custo baixo. Requer restauração antes do download. Opções: Expedited (1-5min), Standard (3-5h), Bulk (5-12h). Mínimo 90 dias.

Arquivamento

Glacier Deep Archive

Menor custo de armazenamento. Recuperação lenta: Standard (12h) ou Bulk (48h). Mínimo 180 dias. Para documentos raramente acessados.

Longo prazo

Versionamento

Mantém todas as versões de um objeto. Permite recuperar versões anteriores. Delete markers indicam exclusão lógica. Essencial para compliance.

Histórico

Lifecycle Rules

Regras automáticas que transitam objetos entre classes ou os expiram. Processamento assíncrono (não instantâneo). Baseado na idade do objeto.

Automação

URLs Pré-assinadas

URLs temporárias que permitem upload ou download sem expor credenciais. Expiram após tempo configurado. O arquivo vai direto ao S3 sem passar pelo servidor.

Segurança
